# Portfolio Review Guide

This repository is designed for a short, evidence-based review.

## If you have 60 seconds

- Read the [portfolio README](../README.md).
- Open the runnable [Governed AI Control Plane](https://github.com/lpssovereign/lps_control_plane).
- Choose the case study nearest your role: [PhiNeX](../case-studies/phinex.md) for legal tech or [Vizion](../case-studies/vizion.md) for guided learning and edtech-adjacent systems.

## If you have five minutes

1. Inspect the control plane's state, policy, audit, and test files.
2. Read the [Legal AI Implementation Walkthrough](LEGAL_AI_IMPLEMENTATION_WALKTHROUGH.md).
3. Review the [public/private evidence standard](PUBLIC_PORTFOLIO_BOUNDARY.md).

## What is evidenced publicly

- working Python reference code, automated tests, examples, and CI;
- architecture diagrams and operating models;
- explicit implementation-maturity labels;
- workflow discovery, governance, integration, and adoption thinking.

## What is intentionally not public

Private records, credentials, customer data, deployment infrastructure, proprietary orchestration and ontology, reusable internal workflow libraries, and protected implementation details.

## Best-fit conversations

- AI solutions engineer
- implementation or forward-deployed engineer
- AI enablement and adoption
- responsible AI or governance
- workflow automation and systems integration
- legal-tech or edtech implementation
